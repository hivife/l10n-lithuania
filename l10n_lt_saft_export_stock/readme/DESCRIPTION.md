Adds the stock related parts to the Lithuanian SAF-T file generated by
`l10n_lt_saft_export`:

- `MasterFiles/MovementTypeTable`: movement types used in the file
  (`PIR` purchase, `PARD` sale, `PG` / `PRG` returns, `VP` internal transfer,
  `N` write-off, `PP` production, `KT` other)
- `MasterFiles/PhysicalStock`: opening and closing quantity and value per product
- `SourceDocuments/MovementOfGoods`: done stock moves grouped by transfer, with
  quantity, book value and warehouse
- the valuation method of the products (FIFO, average, standard)

The module is installed automatically when both `l10n_lt_saft_export` and
`stock_account` are installed.
