Adds the stock related parts to the Lithuanian SAF-T file generated by
``l10n_lt_saft_export``:

- ``MasterFiles/MovementTypeTable``: movement types used in the file
  (``PIR`` purchase, ``PARD`` sale, ``PG`` / ``PRG`` returns, ``VP``
  internal transfer, ``N`` write-off, ``PP`` production, ``KT`` other)
- ``MasterFiles/PhysicalStock``: opening and closing quantity and value
  per product
- ``SourceDocuments/MovementOfGoods``: done stock moves grouped by
  transfer, with quantity, book value and warehouse
- the valuation method of the products (FIFO, average, standard)

The module is installed automatically when both ``l10n_lt_saft_export``
and ``stock_account`` are installed.

Usage
=====

Generate the SAF-T file as described in ``l10n_lt_saft_export``. The
stock parts are written for the data types ``F`` and ``MG`` (physical
stock also for ``SI`` and ``PI``).

Known issues / Roadmap
======================

- Stock is reported per product for the whole company, not per
  warehouse.
- Movements are valued with the stock move value of Odoo; landed costs
  and later revaluations are not split out.
