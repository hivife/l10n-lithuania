Lithuania SAF-T Export

This module generates the Lithuanian standard accounting data file SAF-T (Standartinė apskaitos duomenų rinkmena, XSD version 2.01) requested by the State Tax Inspectorate (VMI, i.SAF-T) and validates it against the official schema shipped with the module.

All parts of the file are covered:

SAF-T part Source in Odoo
Header company data, SAF-T settings, export wizard
GeneralLedgerAccounts posted journal items; income and expense accounts restart at the beginning of the financial year, the result of previous years is shown on the unaffected earnings account
Customers / Suppliers partners used in the file, receivable / payable balances per account, open invoices at the beginning of the period
TaxTable company taxes; STITaxCode is the VMI tax code of the l10n_lt taxes (fallback PVM100)
UOMTable, Products units of measure and products used in the file
AnalysisTypeTable analytic accounts used in the analytic distribution
Assets, AssetTransactions built-in register of fixed assets (straight-line depreciation)
Owners built-in register of owners / shareholders
GeneralLedgerEntries posted journal entries, grouped by journal
SalesInvoices, PurchaseInvoices customer and vendor invoices and credit notes
Payments entries of bank, cash and credit card journals
MovementTypeTable, PhysicalStock, MovementOfGoods done stock moves, provided by l10n_lt_saft_export_stock

The file can be generated complete (data type F) or split by data type (GL, SI, PI, PA, MG, AS). The data groups written for each data type follow table 5 of the VMI XSD specification.

The module works with Odoo Community Edition and does not depend on any Enterprise module.

Configuration

  1. Company: set the Company ID (JAK, additional identifier Company ID of the company partner) or the Tax ID, the address (city, postal code) and a phone number.
  2. Invoicing > Configuration > Settings > SAF-T Lithuania: set the entity code (Header/Entity), the tax accounting basis (accrual / cash) and the contact person.
  3. Chart of accounts, tab SAF-T (LT): check the SAF-T account type (pre-filled from the Odoo account type) and enter the code and name of the VMI account classifier (Annex 2 of the SAF-T description). Without a classifier code the account code is used.
  4. Journals: check the SAF-T Journal Type (pre-filled from the journal type).
  5. Invoicing > Configuration > SAF-T (LT): register fixed assets and owners.

Usage

  1. Go to Invoicing > Reporting > SAF-T Export (LT).
  2. Choose the period (at most one financial year), the data type (F for the complete file or one of GL, SI, PI, PA, MG, AS) and the tax accounting basis.
  3. Keep Validate against XSD checked and click Generate.
  4. Download the generated XML file and upload it to the VMI i.SAF-T portal.

If mandatory company data is missing, or if the generated file does not match the schema, the wizard shows the problems instead of a file.

Known issues / Roadmap

  • The account classifier codes of VMI (Annex 2 of the SAF-T description) are not pre-filled for the Lithuanian chart of accounts yet.
  • A file is always generated in one part (NumberOfParts = PartNumber = 1); very large files are not split into several parts.
  • Ship-to / ship-from data, order references and settlement discounts of invoices are not exported.
  • Line level tax amounts of invoices are computed from the tax rate; the document totals use the posted tax lines.
  • The asset register is intentionally minimal (straight-line, monthly depreciation) and does not post depreciation entries.
  • The i.SAF monthly invoice register is not part of this module.
