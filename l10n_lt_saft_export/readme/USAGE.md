1. Go to *Invoicing > Reporting > SAF-T Export (LT)*.
2. Choose the period (at most one financial year), the data type
   (`F` for the complete file or one of `GL`, `SI`, `PI`, `PA`, `MG`, `AS`)
   and the tax accounting basis.
3. Keep *Validate against XSD* checked and click *Generate*.
4. Download the generated XML file and upload it to the VMI i.SAF-T portal.

If mandatory company data is missing, or if the generated file does not match the
schema, the wizard shows the problems instead of a file.
