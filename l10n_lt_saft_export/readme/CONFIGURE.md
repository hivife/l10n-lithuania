1. Company: set the Company ID (JAK, additional identifier *Company ID* of the
   company partner) or the Tax ID, the address (city, postal code) and a phone number.
2. *Invoicing > Configuration > Settings > SAF-T Lithuania*: set the entity code
   (`Header/Entity`), the tax accounting basis (accrual / cash) and the contact person.
3. Chart of accounts, tab *SAF-T (LT)*: check the SAF-T account type (pre-filled from
   the Odoo account type) and enter the code and name of the VMI account classifier
   (Annex 2 of the SAF-T description). Without a classifier code the account code is used.
4. Journals: check the *SAF-T Journal Type* (pre-filled from the journal type).
5. *Invoicing > Configuration > SAF-T (LT)*: register fixed assets and owners.
